# Awesome DESIGN.md

A local copy of [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`). Each file at `designs/<name>/DESIGN.md` has YAML front matter with design tokens (`colors`, `typography`, `rounded`, `spacing`, …) followed by prose on components, layout and do's/don'ts.

## How to use

1. Pick the system(s) from the index below that match the request. If the user has not named one, suggest two or three that fit the product and ask, or choose the closest match and say which.
2. Read the chosen `designs/<name>/DESIGN.md` in full before writing any UI code.
3. To give a project a design system, copy the file to the project root as `DESIGN.md` (adapt the `name`, and replace brand-specific names, logos and proprietary fonts with the project's own or with the fallbacks listed in the font stacks).
4. Build from the tokens: map `colors`, `typography`, `rounded` and `spacing` into CSS variables or the project's theme config, then follow the component and layout notes.
5. Use these as style references. Do not reproduce another company's logo, trademarks or product copy, and do not present a page as that company's.

These files describe the brands' public sites as analysed by the community; treat them as inspiration, not official brand guidelines. More previews: https://getdesign.md
